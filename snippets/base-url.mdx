The MarketBox API is currently served from a development host:

```
https://rtgic12qk9.execute-api.us-east-1.amazonaws.com/dev
```

Every example in these docs reads it from `MARKETBOX_API_URL`:

```bash
export MARKETBOX_API_URL="https://rtgic12qk9.execute-api.us-east-1.amazonaws.com/dev"
export MARKETBOX_API_KEY="your-key-here"
```

<Warning>
This host will change when the API moves to its permanent domain. Read it from
an environment variable rather than hard-coding it.
</Warning>
